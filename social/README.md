# social/ — Prepared & Published Content

- `queue/` — Canva-ready (or production-ready) post packages awaiting production/publishing, produced by the `content-creator` skill. Filename: `<YYYY-MM-DD>-<series-slug>.md` (+ any rendered image assets alongside).
- `<pillar-slug>/<series-slug>/` — the archive: once a post is actually published, its package moves here (content-creator Step 8). **Create one folder per content pillar during onboarding**, using the folder slugs from `context/Marketing_Strategy.md` §1.1 (e.g., `educational/`, `storytelling/`, `products/`).

The queue holds only unpublished, ready-to-produce posts.
