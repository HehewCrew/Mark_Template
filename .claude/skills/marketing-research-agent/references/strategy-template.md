# Marketing Strategy Template

Use this structure when creating a marketing strategy doc for a brand that doesn't have one. Adapt section depth to what the research actually found — don't pad sections with assumptions to make them look complete. Every factual claim needs a source note ("per <source>, checked <YYYY-MM>").

```markdown
# <Brand> Marketing Strategy

> Living marketing strategy file for <Brand> — content, audience, growth, and execution.
> Companion to <brand context / product / style docs, if they exist>.
> Last updated: <YYYY-MM-DD>

---

## 1. Content Strategy
### 1.1 Content Pillars
<Pillar table with share-of-content percentages>
### 1.2 Recurring Content Series
<Series grouped by pillar>
### 1.3 Posting Cadence
<Weekly/bi-weekly rotation by day>
### 1.4 Format & Volume Targets
<Formats per week + the metrics that count as success (e.g., saves, shares, watch time)>

## 2. Growth Expectations
<Benchmark table: timeframe → expected follower/reach range, with the source of the benchmark>

## 3. Expansion Strategy
<Year 1 vs. Year 2+ content/product mix; how adjacent offerings get validated before investment>

## 4. Target Audience
<Who, at what skill/intent levels, and which content serves which segment.
Include a planned post-launch adjustment checkpoint: when real engagement data
arrives, which signal triggers rebalancing, and what gets rebalanced.>

## 5. Competitor Landscape
<Per competitor: what they offer, pricing reference points, and what gap the brand
exploits. Source-note every price.>

## 6. Content Reference
<Large accounts in the niche worth learning from — takeaways, not templates to copy.
Current platform best practices with sources.>

## 7. Production Tools
<Confirmed tool per format; open tool decisions flagged>

## 8. Community Guidelines / Moderation Approach
<How the brand handles rudeness/elitism, spam/self-promotion, follower language,
and product questions before specs are locked. Note the team-size assumption.>

## 9. Open / To Be Defined
- [ ] <Every question the user deferred at intake, and every fact research couldn't confirm>
```

Conventions (keep these even for non-chess, non-Instagram brands):

- Resolved open items get checked off (`[x]`), not deleted — the decision history stays visible.
- Update `Last updated:` on every substantive edit.
- If the brand has companion docs (brand context, products, style guide, glossary), cross-reference them in the header blockquote and keep those references accurate.
