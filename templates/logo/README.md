# templates/logo/

Locked brand logo files land here once designed (see `context/Style_Guide.md` §2.4): each lockup (stacked / horizontal / mark-only) in vector + PNG, in transparent and brand-background variants.

Also create `fonts/` here with the brand's TTF/OTF files once typography is locked — the template-generator and dashboard tooling embed them as base64 data URIs.

If the logo is generated programmatically, keep the generator script in `generator/` so it can be regenerated rather than hand-edited.
