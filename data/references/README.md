# data/references/ — Grounding Sources

Drop copies of the brand's reference sources here (PDFs, docs) — the books/publications listed in `context/Brand_Context.md` Section 4.

Rules (from `sop/SOP_Marketing_Research.md`):
- Content is **grounded** in these sources, never copied: always paraphrase in the brand's voice, never reproduce source text verbatim, never scan/screenshot source imagery into posts.
- When a source is added, map it to the series it can feed in the Appendix of `data/content_planner.md`.
