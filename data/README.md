# data/

Working data for the brand's content operation:

- `content_planner.md` — the episode schedule + done-log consumed by the `content-creator` skill.
- `examples/` — content-generation reference material: craft/best-practices docs plus `examples/posts/`, the confirmed-template library read by content agents (mirrored from `templates/`).
- `references/` — copies of the brand's grounding sources (books/PDFs/docs from `context/Brand_Context.md` Section 4). Content paraphrases these — never verbatim.
- `analysis/` — intake folder for unprocessed analytics exports, consumed by the `data-analyzer` skill per `sop/SOP_Data_Analysis.md` (processed files move to `presentations/data-analysis/`).
- `research_reports/` — monthly strategy-proposal reports from the automated research run (`sop/SOP_Marketing_Research.md` §2.5) awaiting owner review.
